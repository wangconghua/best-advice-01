One original sentence about the best advice the writer ever received:
a first boss, an angry customer, and the line that kept a young worker
from quitting on a bad day. A real moment, a real person, plain voice —
no slogan, no fortune cookie.

## Run it

```sh
python3 main.py
```

It validates the sentence (one sentence, 1–200 characters, a named
person giving quoted advice) and writes it to `/output/entry.txt`
(or `$ENTRY_OUTPUT`).
